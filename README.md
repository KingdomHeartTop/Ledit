# 🎮 LEdit — Level Editor

> Создавай уровни для любых игр. Поддержка 20+ языков и форматов.

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

## 🚀 Возможности

- ✨ 3D-редактор уровней
- 🛡️ Встроенная проверка на вирусы
- 📦 Система плагинов
- 📤 Экспорт в 6+ форматов
- 🌐 7 языков интерфейса
- 🔄 Кроссплатформенность

## 📦 Установка

```bash
git clone https://github.com/YOUR_USERNAME/ledit.git
